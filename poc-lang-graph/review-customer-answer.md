# INSTRUCTIONS
A human operator must review the drafted message before it is sent to the external ticketing system.

1. **Verification:** Check for technical accuracy and tone.
2. **Decision:** Approve to proceed to delivery, or reject and provide feedback for a rewrite.

# REQUIRED INPUTS
- `ticketId`: Current ticket.
- `responseDraft`: The draft generated by the agent.

# EXPECTED OUTPUTS
- `isApproved`: Boolean (true/false) indicating if the message is approved.
- `humanFeedback`: Detailed instructions if the draft needs changes.
