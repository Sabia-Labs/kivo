# INSTRUCTIONS
Your goal is to organize and refine the current project backlog to ensure the engineering team has clear, prioritized work.

1. **Tool Discovery:** Identify your project management tool (Linear, Notion, GitHub Issues, etc.). If not configured or the path is unknown, update the Kivo Task status to `waiting_user` and ask the Operator for the setup details.
2. **Backlog Scan:** Scan all items in "Inbox", "Unsorted", or with "Backlog" status.
3. **Draft Proposal:** Prepare a proposed reorganization. For each item, refine the title, add missing acceptance criteria, and suggest a priority level based on the product vision.
4. **Operator Confirmation:** Summarize your proposed changes (which items will be prioritized, which were refined, and any potential duplicates found). Update the Kivo Task to `waiting_user` and ask for the Operator's approval before applying the changes to the tool.
5. **Finalize:** Once the Operator approves or provides feedback, apply the changes in the tool and move ready items to the "Ready for Engineering" or equivalent state.

# INPUTS

# EXPECTED OUTPUTS
- A summary of the proposed backlog reorganization for Operator approval.
- Confirmation of final changes applied after approval.
