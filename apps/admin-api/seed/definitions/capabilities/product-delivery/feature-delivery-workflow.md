# MISSION
This workflow automates the complete lifecycle of a new feature: from its definition and refinement as a User Story, through technical implementation, to a final architectural code review. It ensures speed without sacrificing clarity or quality.

# WAYS OF WORKING
1. **Definition:** The Product Manager starts by creating a clear User Story.
2. **Execution:** Once the Story is ready, the Software Engineer takes over to implement and open a Pull Request.
3. **Validation:** Finally, the Software Architect (or Team Lead) reviews the PR to ensure it meets the project standards.
