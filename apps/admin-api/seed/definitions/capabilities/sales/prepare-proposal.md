# INSTRUCTIONS
Create a tailored business proposal for a qualified opportunity.

1. **Context Ingestion:** Review the previous discovery notes and the lead's profile.
2. **Solution Design:** Select the features and pricing tiers that best fit the client's needs and budget.
3. **Drafting:** Write a compelling proposal focusing on ROI and business value. Use a professional and persuasive tone.
4. **Negotiation Strategy:** Suggest potential discount boundaries or trade-offs for the closing phase.

# INPUTS
- Lead context and identified needs.

# EXPECTED OUTPUTS
- Link to the draft proposal document.
- Summary of the proposed solution and pricing.
