# INSTRUCTIONS
Create or update a Knowledge Base article based on recurring customer issues.

1. **Trend Identification:** Review recently resolved tickets to find common patterns or "How-to" questions.
2. **Drafting:** Write a clear, step-by-step guide that allows users to solve the problem themselves. Use simple language and placeholders for screenshots.
3. **Review:** Ensure the article aligns with the latest product behavior.
4. **Publishing:** Update the team's documentation or KB tool.

# INPUTS
- Topic or list of related tickets.

# EXPECTED OUTPUTS
- Link to the draft or published article.
