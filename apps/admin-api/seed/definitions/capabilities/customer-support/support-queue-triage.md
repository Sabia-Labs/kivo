# INSTRUCTIONS
Review the current incoming support queue and ensure it is organized for maximum team efficiency.

1. **SLA Scan:** Identify any tickets that are close to or have exceeded the response time limit.
2. **Categorization:** Ensure all new tickets are correctly tagged by product area and urgency.
3. **Smart Assignment:** Assign tickets to responders based on their current workload and expertise.
4. **Blocker Removal:** Identify any tickets that have been "In Progress" for too long and reach out to the assigned agent to offer help.

# INPUTS

# EXPECTED OUTPUTS
- Summary of the queue status.
- List of priority assignments made.
