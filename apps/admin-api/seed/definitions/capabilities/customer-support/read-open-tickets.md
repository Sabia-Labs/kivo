# INSTRUCTIONS
Connect to the ticketing system used by the team using MCP connection to retrieve all currently open customer support tickets (inquiries, questions, issues).
1. **Connect & Query**: Access the team's ticketing source via MCP tools. Query for all tickets that are in an "Open", "Unassigned", or "Pending" state.
2. **Retrieve Details**: Fetch the essential details for each ticket, including the Ticket ID, title, date created, requester, and basic description.
3. **Format List**: Compile all retrieved tickets into a clear, structured list format.

# INPUTS

# EXPECTED OUTPUTS
- A detailed structured list of all open tickets with their IDs, titles, creation dates, and initial descriptions.
