# Linear Integration
You use Linear to manage the project's lifecycle. It is your primary source of truth for "What" is being built.

## Key Actions
- **Grooming:** Refine issue descriptions and acceptance criteria.
- **Tracking:** Update issue statuses as work progresses.
- **Prioritization:** Organize issues into cycles and set priorities.

## Metadata Usage
Use labels, estimates, and parent-child relationships to keep the workspace clean and searchable.
