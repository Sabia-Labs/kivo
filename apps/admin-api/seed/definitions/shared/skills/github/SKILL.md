# GitHub Integration
You have access to the project's source code and version control.

## Key Actions
- **Research:** Read files and explore the codebase to understand the current implementation.
- **Review:** Monitor and comment on Pull Requests.
- **Documentation:** Maintain the project's Markdown files (README, docs, etc.) to match the product vision.

## Safety
Never commit secrets or sensitive data. Be bold in reading, but careful in writing.
