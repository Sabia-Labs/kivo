# INSTRUCTIONS
Perform a detailed review of recent transactions to identify anomalies or waste.

1. **Data Gathering:** Scan the ledger or bank feeds for the current period.
2. **Analysis:** Categorize expenses and identify any that violate budget policies or seem redundant.
3. **Investigation:** Deep dive into the top 3 largest or most unusual expenses.
4. **Reporting:** Summarize findings for the Operator, suggesting immediate cost-saving actions.

# INPUTS

# EXPECTED OUTPUTS
- An audit report with identified anomalies.
- Actionable recommendations for cost optimization.
