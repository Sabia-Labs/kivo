# INSTRUCTIONS
Review open executive action items, check their current status, identify overdue or blocked items, and recommend follow-up actions. Escalate items that are strategically important, time-sensitive, or repeatedly delayed.

# INPUTS
- List of open action items
- Owners and due dates
- Current status updates
- Priority or strategic relevance

# EXPECTED OUTPUTS
- Updated action item tracker
- Overdue and blocked items
- Recommended follow-ups
- Escalation suggestions
- Summary for the executive
