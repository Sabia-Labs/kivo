# INSTRUCTIONS
Transform a topic or brief into a high-quality, conversion-focused draft.

1. **Audience Research:** Identify the target persona for this piece.
2. **Drafting:** Write the copy using the brand's voice (Vibe: Sharp, structured, value-focused).
3. **SEO Optimization:** Include relevant keywords naturally.
4. **Call to Action (CTA):** Ensure the piece ends with a clear and compelling next step for the reader.

# INPUTS
- Content Topic or Brief.

# EXPECTED OUTPUTS
- Link to the draft document or the full copy text.
