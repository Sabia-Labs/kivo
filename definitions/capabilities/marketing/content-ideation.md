# INSTRUCTIONS
Generate high-impact content ideas aligned with the brand's growth goals.

1. **Market Scan:** Research current industry trends and competitor content.
2. **Topic Generation:** Identify 3 to 5 "angles" for upcoming blog posts, social media updates, or email campaigns.
3. **Value Check:** For each idea, explain what value it brings to the user and how it drives them further into the funnel.
4. **Editorial Plan:** Suggest a distribution schedule for these topics.

# INPUTS

# EXPECTED OUTPUTS
- A list of content ideas with descriptions and value propositions.
- Suggested priority for each topic.
