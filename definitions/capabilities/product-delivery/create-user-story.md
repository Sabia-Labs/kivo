# INSTRUCTIONS
Transform a high-level feature request into a detailed User Story ready for engineering.

1. **User Goal:** Write the story in the format: "As a [role], I want to [action], so that [value]".
2. **Contextual Alignment:** Ensure the story fits within the current product architecture and goals.
3. **Acceptance Criteria:** Define at least 3 clear, testable "Definition of Done" criteria.
4. **Issue Creation:** Create the Issue in the project management tool and link it to any relevant parent project.

# INPUTS
- Feature request or goal description.

# EXPECTED OUTPUTS
- Link to the newly created User Story Issue.
- Identification of the created Issue ID for the next workflow step.
