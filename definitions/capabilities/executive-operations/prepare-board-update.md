# INSTRUCTIONS
Prepare a structured board update using company metrics, strategic priorities, risks, recent progress, and key decisions needed. Keep the output concise, factual, and suitable for executive review before sharing externally.

# INPUTS
- Company metrics
- Recent progress updates
- Strategic priorities
- Risks and blockers
- Decisions or asks for the board
- Optional previous board update

# EXPECTED OUTPUTS
- Draft board update
- Key highlights
- Risks and mitigations
- Decisions needed
- Suggested talking points
