# INSTRUCTIONS
Review current OKRs, progress updates, confidence levels, blockers, and dependencies. Produce a concise leadership-level check-in that identifies what is on track, what is at risk, and what decisions or interventions are needed.

# INPUTS
- Current OKRs
- Key result progress
- Confidence levels
- Blockers and dependencies
- Recent status updates

# EXPECTED OUTPUTS
- OKR progress summary
- On-track items
- At-risk items
- Blockers and dependencies
- Recommended leadership actions
